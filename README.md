# Marketing Mastery Hub

Build a modern highly polished and responsive personal portfolio website for an aspiring Marketing director professional. Use Next.js/React and Tailwind CSS with a clean, dark-mode default aesthetic. it must include:
1. Sticky Navigation Bar (smooth scrolling links to sections, mobile hamburger menu)
2. Hero section (Name, headline, short elevator pitch, 'Download Resume' button, and 'Contact me' CTA)
3. About me and qualifications (educational background. degree/diploma).
4. Skills Grid (categorized: Frontend, Backend, Tools and DevOps, soft skills)
5. certification section (cards with credential names, issuing org, issue date and credential link/badge). 
6. Projects showcase ( cards with project thumbnails, tags/tech stack, brief description, live demo link and GitHub)
7. contact section (working contact form UI, email, Linkedin, Gi, GitHub)
8. Footer (copyright, social links). 
Ensure smooth responsiveness across desktop, tablet and mobile screens.
